### 2. Code Blocks with Syntax Highlighting

```python
def make_everything_cool():
    """
    A function that makes everything cool!
    """
    cool_things = ['code', 'design', 'ideas']
    return [f"{thing} 😎" for thing in cool_things]

print(make_everything_cool())
```

```javascript
// Cool JavaScript example
const coolify = (items) => {
  return items.map(item => `${item} is cool! 🎉`);
};

console.log(coolify(['Coffee', 'Code', 'GitHub']));
```
